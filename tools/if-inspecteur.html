Inspecteur de dossier Infinite Fusion

Cette page regarde le contenu du dossier du jeu sur ton téléphone et écrit un rapport à copier pour Claude. Tout se passe dans ton navigateur : aucun fichier n'est envoyé.

Étape 1

Trouver le dossier du jeu

  1. Ouvre ton gestionnaire de fichiers (« Fichiers », « Mes fichiers »…).
  2. Cherche CustomBattlers avec la loupe.
  3. Le dossier du jeu est celui qui contient Graphics (le parent du parent de CustomBattlers).
Étape 2

Le donner à la page

Après avoir choisi un dossier, Chrome peut demander « Importer N fichiers sur ce site ? » : réponds Importer. Avec beaucoup de fichiers, Chrome peut mettre plusieurs minutes avant de rendre la main : laisse l'écran allumé.

Si le dossier entier ne passe pas, ajoute des petits dossiers un par un (le bouton peut servir plusieurs fois, tout s'additionne) : PBS, puis Data, puis Graphics/Battlers, puis Graphics/CustomBattlers. Si un seul petit morceau passe, le rapport sera déjà utile.

En attente d'un dossier ou d'un zip.
